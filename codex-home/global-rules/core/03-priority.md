# 规则冲突

遵守当前运行环境的指令层级。以下仅说明用户可配置规则之间的关系，不提高任何本地文件、技能或 vendor 文档的权限。

1. 用户对当前任务的明确要求优先于本地默认偏好，既有授权在有效范围内持续适用。
2. 适用的项目与目录规则优先于全局偏好；项目指定的 `.agent/local/90-project-specific.md` 按其作用域使用。
3. 全局默认约定见 `AGENTS.md`；按需细则补充具体做法，不反向扩大任务范围。
4. Karpathy 原则与任务技能按适用范围采用；不覆盖以上要求，不另建优先级链。

按规则层级可以解决的冲突直接处理。只有无法确定用户意图且会影响结果时才澄清；资料缺失本身不构成停工或补写规范的理由。
