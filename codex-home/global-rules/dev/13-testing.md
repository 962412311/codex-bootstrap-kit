# 验证范围

优先运行项目规定的检查与本次改动直接相关的验证；已通过后，仅因新修改、失败或未解决风险扩大或重跑。

| 改动 | 优先证据 |
|---|---|
| 逻辑与故障修复 | 能区分修复前后的行为验证、必要边界 |
| 重构 | 相关行为保持一致；按影响选择类型检查、构建等 |
| UI 与交互 | 目标界面、关键流程及受影响的空态或错误态 |
| 配置 | 原生解析器或配置读取结果、必要的运行验证 |
| 文档与目录 | 链接、路径、命令与当前实现一致 |

不为低风险文本修改新增镜像实现的测试。编译通过、文件存在或进程存活，只证明相应环节。无法验证时说明缺失环节与原因，不宣称完整通过。
