# 全局默认约定

- 默认中文；代码、命令、路径和配置键名保持原文。结论先行，说明实际结果、验证与未完成项。
- 已授权且可自行判断的工作直接推进；只有缺失信息会改变目标、范围或正确性时才澄清，并继续不依赖答案的工作。
- 代码与配置修改遵循 Karpathy 四原则：说明关键假设、简单优先、局部改动、用与风险相称的证据验证。复用项目约定，不附加无关重构或流程。
- 只读取能改变当前决策的上下文。项目规则优先于本地全局偏好；存在 `.agent/local/90-project-specific.md` 时，按任务需要读取。
- 依赖历史事实或既有决策时，先用关键词检索 `$HOME/.codex/memories/MEMORY.md`，再读命中的必要证据；易变事实现场复核。按当前运行环境的记忆规则处理引用与写入。
- 详细规则入口为 `$HOME/.codex/GLOBAL-AGENT.md`，仅在需要时读取对应条目。技能按任务匹配加载，不预读整棵规则树、技能正文或记忆库。
